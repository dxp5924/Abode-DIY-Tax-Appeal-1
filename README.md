# Abode DIY Property Tax Appeal MVP

Interactive prototype for a Broward County, Florida DIY property tax appeal experience.

## Open locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Open **Settings -> Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public site URL after deployment.

## Current prototype scope

- Address-first onboarding with simulated Broward property matching
- Personalized savings estimate
- DIY eligibility and exception routing
- Copy-ready filing worksheet
- County portal handoff
- Filing confirmation capture
- Hearing and evidence deadline preparation
- Result capture
- Guardrailed self-service chatbot
- Operator view covering the four case-study questions

## Important

This is a case-study prototype. Live property lookup, authentication, county integrations, payments, production AI, appointment scheduling, and persistent backend storage are simulated.
